Data Structures & Algorithms Tasks

This repository contains my solutions to the **Data Structures and Algorithms (DSA)** tasks assigned .


### 1. Second Largest Element in an Array
*   **Description: Finds the second largest distinct element in a given array of integers.
*   **Approach: Solved in a single pass (O(N) time) by maintaining two variables.

### 2. Balanced Brackets
*   **Description: Checks if an input string of brackets `(`, `{`, `[`, `)`, `}`, `]` is valid and balanced.
*   **Approach: Utilised a Stack data structure. Pushed opening brackets and matched them against closing brackets.


### 3. Binary Concatenation Tree Construction
*   **Description: Constructs a binary tree based on binary string concatenations and evaluates its properties.
*   **Approach: Built the tree recursively from the binary strings, tracking node values.

### 4. Tree Diameter and Leaves
*   **Description: Calculates the longest path between any two nodes (Diameter) and counts the total leaf nodes in the constructed binary tree.
*   **Approach: 
    *   **Diameter: Used a post-order traversal to calculate height and diameter simultaneously in O(N) time.
    *   **Leaves: Traversed the tree recursively, counting nodes with both left and right children as null.


### 5. Subarray Sum Equals K
*   **Description: Finds the total number of continuous subarrays whose sum equals a given value `k`.
*   **Approach: Implemented using a Prefix Sum combined with a Hash Map (O(N) time and O(N) space) to avoid the O(N²) brute-force approach.

### 6. Stone Game V (LeetCode 1563)
*   **Description: A hard game-theory problem where Bob and Alice split a row of stones, and Alice tries to maximize her score based on the smaller sum partition.
*   **Approach: Solved using Dynamic Programming (DP) with memoization to store optimal choices for any sub-segment of stones
